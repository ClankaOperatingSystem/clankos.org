Clanka Operating System

The operating system for clankas.

What matters is the protocols of interaction, the behaviour and the information management. The tools should not matter. The first implementation uses Emacs; a second is in Python.

  • poslib, the Emacs Lisp library
  • pyposlib, the Python library
