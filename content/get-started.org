#+TITLE: Get Started
#+DESCRIPTION: Start your tree of responsibility with ClankOS.
#+OPTIONS: title:nil

Start in an empty Git repository with Git, Bash, Docker and tar available.
Select a published fixed ClankOS release and replace =vX.Y.Z= below with its
version. The runtime and skills images must both be available for that release.

#+begin_src sh
sh -c "$(curl -fsSL https://www.clankos.org/initiate.sh)" -- vX.Y.Z
#+end_src

The script downloads the release's bootstrap bundle, checks its image pair,
creates the initial configuration and installs the skills. It stages and
commits nothing. Review the changes before committing them.

The installed skills carry their own commands. A fresh clone can use those
bundles directly. Optional methodologies can be selected after bootstrap.

For the protocol, read [[https://github.com/ClankaOperatingSystem/clankos/blob/master/docs/initiate.txt][the bootstrap documentation]].
