#+TITLE: Get Started
#+DESCRIPTION: Start your tree of responsibility with ClankOS.
#+OPTIONS: title:nil

It's probably best to start your tree of responsibility
in an empty git repository.

You will need docker.

#+begin_src sh
sh -c "$(curl -fsSL https://www.clankos.org/initiate.sh)"
#+end_src

You should find this script readable. It will:
- download the ClankOS docker image
- ask some questions and build an initial configuration
- commit nothing

For more information, ask your robot (or read the source).
