The operating system for clankas.

What matters is the protocols of interaction, the behaviour and the
information management. The tools should not matter. The first
implementation uses Emacs; a second is in Python.

- [[https://github.com/ClankaOperatingSystem/poslib][poslib]], the Emacs Lisp library
- [[https://github.com/ClankaOperatingSystem/pyposlib][pyposlib]], the Python library
- [[https://github.com/ClankaOperatingSystem/clankos.org][clankos.org]], this page
